Parakeet Ultra
--------------
ASR weights: https://huggingface.co/moondream/parakeet-ultra
Base model: https://huggingface.co/nvidia/parakeet-tdt-0.6b-v3
FP16 GGUF conversion: https://huggingface.co/handy-computer/parakeet-ultra-gguf
Pinned conversion revision: a1539be1b849ea7463b88343e5277b373d0c4ea9
Weights license: Creative Commons Attribution 4.0 (CC-BY-4.0).
https://creativecommons.org/licenses/by/4.0/
Native ASR runtime/bindings: https://github.com/handy-computer/transcribe.cpp
Version: v0.4.1; native CUDA 12 provider, no PyTorch dependency.
Runtime/bindings license: MIT; bundled third-party code retains upstream licenses.
The GGUF retains upstream weights at FP16 precision. The runtime implements
the model frontend, TDT decoder and word timing; the host selects CUDA explicitly.

Smart Turn
----------
The downloaded Smart Turn v3 ONNX model is distributed by onnx-community,
based on pipecat-ai/smart-turn-v3, under the BSD-2-Clause license.
Source: https://huggingface.co/onnx-community/smart-turn-v3-ONNX
Inference/preprocessing reference: https://github.com/pipecat-ai/smart-turn
Its Whisper-derived encoder is used solely for end-of-turn classification.

Language identification
-----------------------
langid.py 1.1.6, BSD-3-Clause. Small CPU statistical language-identification model.
Source: https://github.com/saffsd/langid.py
No external translation API is used; English glosses are generated by the existing local Qwen model.

Context architecture reference
------------------------------
Redis Iris / LangCache concepts inspired the local cache and memory flow.
https://redis.io/docs/latest/develop/ai/context-engine/
The embedded SQLite implementation is original project code; no Redis service or SDK is required.
